# Helios Development Platform

Tools Qwen uses to build, validate, and deploy applications. Implements part 1 of the architecture (`specs/architecture-mermaid.md`).

- `financial-tools/` — Financial Tools Interface + SDK
- `app-builder/` — app specifications, templates, integration tooling
- `agent-toolkit/` — frameworks for building agents (action + audit)
- `validation/` — checks generated applications before deployment
- `deployment/` — automated deployment with revision feedback to Qwen

Python package structure will be added here as implementation begins.
